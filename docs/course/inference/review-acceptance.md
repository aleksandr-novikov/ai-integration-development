## Ограничения

**Смешанный режим одноимённых таблиц.** Binding выводит имя таблицы из legacy-контура,
поэтому источник без binding не получает оценок и уведомлений. Метрики не теряются,
а при добавлении binding история будет оценена. Сценарий обнаруживается: запись
`unsupported mixed serving` в журнале и предупреждение на странице «Версии оценок».
Безопасный режим — binding для всех одноимённых источников; для него подтверждены
независимые оценки, уведомления и объяснения. Графики, прогноз, дрейф и change-points
по-прежнему объединяют подключения по имени таблицы; change-points в prompt такого
источника помечаются `not available`.

Отдельная техническая задача: передать полный source в legacy feature builder,
обучение, пути mutable-артефактов и фоновые задания; новые legacy-оценки хранить
с полным source и маркерами версии, старые артефакты и строки не перепривязывать.
Приёмка: два подключения с одинаковой таблицей, модель только у одного; оба
независимо оцениваются и уведомляют, история и UI не смешиваются.

**Ручная оценка неактивной версией.** Если она выполнена раньше фонового тика для
ещё не оценённой точки, отметка времени сдвигается и уведомления об этой точке нет.

**Legacy-уведомления.** Как и в `master`, legacy-контур на каждом тике берёт последнюю
аномалию за сутки и ограничен только throttle, поэтому может повторять её после
истечения окна. Поведение не менялось.

**Миграции.** PostgreSQL advisory lock защищает конкурирующие новые workers;
версионированного runner и межпроцессной блокировки SQLite нет. Окно обслуживания,
backup и репетиция обязательны; прямой downgrade небезопасен. Integration CI проверяет
PostgreSQL-миграцию и создание новой схемы с hypertable. Обновление существующей
hypertable с данными не подтверждено. [Runbook](migrations.md).

**Доставка.** Telegram не транзакционен с БД: для гарантированной доставки после
сбоя процесса нужен outbox. Реальные NIM и Telegram не вызывались.

**Активация.** Источник выбора в адаптере — bindings. Команда `activate` реестра не
переключает их автоматически. Модель #9 остаётся demo/rejected: технические проверки
не означают допуск её качества.

Источник: [презентация](presentations/В09_API_FastAPI.pdf), **слайд 41**; [карточка ЛМС](https://netology.ru/profile/program/bhemai-25-iair-3/lessons/658299/lesson_items/3564573).

- [ ] Реализовать минимум **три эндпоинта**.
- [ ] Проверить их через **Swagger UI** и сохранить способ проверки/результаты.

### В10. Стратегия деплоя

Источник: [презентация](presentations/В10_Стратегии_деплоя.pdf), **слайд 45**; [карточка ЛМС](https://netology.ru/profile/program/bhemai-25-iair-3/lessons/658300/lesson_items/3596671).

- [ ] Подготовить **две страницы**: схема и описание стратегии деплоя.
- [ ] Указать критерии успешности, измеримые пороги и план отката.

Уточняет задачу #14. Отдельный практический запуск отката остаётся проверкой проекта, но в тексте слайда явно требуется прежде всего схема и описание.

### В11. Docker и Compose

Источник: [презентация](presentations/В11_Docker_Compose.pdf), **слайд 46**; [карточка ЛМС](https://netology.ru/profile/program/bhemai-25-iair-3/lessons/658301/lesson_items/3699549).

- [ ] Подготовить `Dockerfile` и `docker-compose.yml` для проекта.
- [ ] При наличии Docker проверить сборку.
- [ ] Если Docker недоступен, сдать корректные файлы и описать способ их проверки — такой вариант прямо разрешён в слайде.

Уточняет задачу #13. Наличие файлов в репозитории не заменяет проверку их соответствия текущему учебному сервису.

### В12. Мониторинг

Источник: [презентация](presentations/В12_Мониторинг.pdf), **слайд 41**; [карточка ЛМС](https://netology.ru/profile/program/bhemai-25-iair-3/lessons/658302/lesson_items/3699550).

- [ ] Добавить логирование и метрики в сервис.
- [ ] Спроектировать **эскиз дашборда** и дать текстовое описание.

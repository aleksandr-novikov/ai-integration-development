# Итоговый отчёт (#19)

[REPORT.md](REPORT.md) — редактируемый текст, [REPORT.pdf](REPORT.pdf) — документ для сдачи
(A4, 6 страниц). Отчёт обобщает уже выполненные задачи курса и ссылается на их первичные
материалы; новые эксперименты, обучение и изменения кода для него не выполнялись.
Требование к объёму — 5–7 страниц A4 ([план курса](../ROADMAP.md), этап М5).

## Сборка PDF

PDF строится из `REPORT.md` тем же способом, что и [стратегия деплоя](../deployment/README.md):
ReportLab и Unicode TTF-шрифты, пути к которым передаются аргументами. Относительные ссылки
превращаются в ссылки на файлы ветки `master` на GitHub, чтобы PDF работал вне репозитория.
Ширины колонок таблиц задаются комментарием `<!-- widths: … -->`.

```bash
python docs/course/final/render_pdf.py \
  --font /usr/share/fonts/truetype/dejavu/DejaVuSans.ttf \
  --bold-font /usr/share/fonts/truetype/dejavu/DejaVuSans-Bold.ttf \
  --mono-font /usr/share/fonts/truetype/dejavu/DejaVuSansMono.ttf
```

Проверено 12.11.2026: ReportLab 4.2.5 во временном venv вне репозитория, DejaVu Sans.
Результат — A4, **6 страниц** (подсчёт pypdf и PyMuPDF); все страницы отрисованы и
просмотрены: таблицы и схема не обрезаны, кириллица отображается, основной текст 9,6 pt.
Повторная сборка даёт побайтово тот же файл (`rl_config.invariant`). Ссылки на файлы
репозитория проверены на существование; внешние ссылки на GitHub отвечали 200.
После правки `REPORT.md` PDF нужно пересобрать; если страниц станет больше семи,
сокращать текст, а не уменьшать шрифт.
